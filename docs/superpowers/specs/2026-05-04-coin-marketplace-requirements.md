> 文档版本：v1.0
> 编制日期：2026-05-04
> 文档状态：草稿（待客户确认）

---

## 1. 项目概述

### 1.1 项目背景

建设一个面向全球的钱币收藏品在线交易平台。平台支持**固定价格商城**与**未来拍卖系统**两大交易模式，第一期先实现固定价格商城，预留拍卖模块扩展点。

### 1.2 平台定位

- **平台类型**：B2C（平台自营）+ C2C（藏家之间交易）混合模式
- **商品品类**：纪念币、古钱币、金银币、纸币等钱币收藏品
- **目标市场**：新加坡、马来西亚为主，覆盖中国、日本、欧美市场

### 1.3 项目目标

- 一期：建成支持多语言、多币种、多支付方式的固定价格商城
- 二期：接入/自建拍卖系统，扩展交易模式
- 长期：成为东南亚地区领先的钱币收藏品交易平台

## 2. 功能需求

### 2.1 用户系统

#### 2.1.1 注册与登录
- 支持邮箱注册、手机号注册（支持国际区号）
- 支持第三方登录（Google、微信）
- 注册信息需含：用户名、邮箱、手机号、密码、偏好语言
- **便捷注册**：注册流程控制在 3 步以内完成
- 支持密码找回、邮箱/手机验证码

#### 2.1.2 买家功能
- 商品浏览、搜索、筛选
- 加入购物车、下单购买
- 订单管理：查看订单状态、历史订单
- 收货地址管理（支持多国地址格式）
- 收藏/关注商品
- 售后申请（退/换货）

#### 2.1.3 卖家功能
- 卖家入驻申请
- 商品发布、编辑、上下架
- 订单处理：确认发货、查看销售记录
- 卖家店铺页面
- 交易统计（简易版）

#### 2.1.4 卖家资质认证
- 入驻需提交：**身份证明**、**电话实名认证**
- 认证后用户**不可自行修改**个人信息，需**后台管理员**才能修改
- 认证资料加密存储，严格权限控制

### 2.2 商品系统

#### 2.2.1 商品信息
- 商品标题、描述、价格、库存
- 多张图片（高清图，支持放大查看细节）
- 品类/标签（按国家、年份、材质、面值等分类）
- **卖家自行描述商品**，平台不提供鉴定服务

#### 2.2.2 第三方评级公司支持
- 支持 **NGC、PCGS、PMG** 等主流评级机构
- 评级编号查询（通过评级编号检索商品）
- 评级信息展示（评级等级、编号、认证标签图片）
- 商品可按评级等级筛选和排序

#### 2.2.3 搜索与发现
- 关键词搜索（商品名、描述、评级编号）
- 多维度筛选（价格区间、评级等级、发行年份、国家、材质）
- 排序（价格、最新、评级等级）

### 2.3 订单系统

- 购物车 → 确认订单 → 支付 → 完成
- 订单状态流转：待支付 → 待发货 → 已发货 → 已完成 → 已取消
- 退款/售后流程
- 订单日志（记录每一步操作）

### 2.4 支付系统

#### 2.4.1 支持的支付方式
| 支付方式 | 适用地区 | 说明 |
|---------|---------|------|
| 微信支付 | 中国大陆 | 二维码/H5 |
| 支付宝 | 中国大陆 | 二维码/H5 |
| 信用卡 | 全球 | Visa, MasterCard |
| PayPal | 全球 | 支持多币种 |
| PayNow | 新加坡 | 本地实时转账 |
| GrabPay | 马来西亚 | 本地电子钱包 |
| FPX / Online Banking | 马来西亚 | 网上银行转账 |

#### 2.4.2 支付要求
- 统一支付网关，根据买家地区自动推荐支付方式
- 支持多币种结算（SGD、MYR、CNY、JPY、USD）
- 支付失败自动重试/Cancel 处理
- 交易对账功能（每日自动对账）
- 退款原路返回

### 2.5 多语言系统（四国语言）

#### 2.5.1 支持语言
| 语言 | 代码 | 适用范围 |
|------|------|---------|
| 简体中文 | zh-CN | 前台全站 + 后台 |
| 繁体中文 | zh-TW | 前台全站 + 后台 |
| 英文 | en | 前台全站 + 后台 |
| 日文 | ja | 前台全站 + 后台 |

#### 2.5.2 语言要求
- 用户可自由切换语言
- 注册时选择偏好语言，后续可修改
- 所有前端页面需翻译（含商品描述是卖家填写，不做翻译）
- 后台管理界面也支持四国语言
- 系统通知/邮件模板支持多语言

### 2.6 后台管理系统

#### 2.6.1 用户管理
- 用户列表、搜索、详情
- **卖家资质审核**（身份证明审核、实名认证审核）
- **卖家信息修改权限**（仅管理员可修改认证后的卖家信息）
- 账号冻结/启用

#### 2.6.2 商品管理
- 商品审核（B2C 自营商品上架审核）
- 商品下架/违规处理
- 分类、标签管理

#### 2.6.3 订单管理
- 全部订单查看、干预
- 退款处理
- 交易纠纷仲裁

#### 2.6.4 支付与财务
- 交易流水查看
- 对账管理
- 提现管理（卖家的销售收入提现）
- 平台佣金/手续费设置

#### 2.6.5 内容管理
- 首页 Banner 配置
- 公告管理
- 多语言文案管理

#### 2.6.6 系统管理
- 管理员账号/角色/权限管理（RBAC）
- 操作日志
- 系统配置

### 2.7 拍卖系统（二期/预留）

- 预留拍卖模块扩展点（数据库、API 接口、事件机制）
- 支持接入第三方拍卖系统
- 拍卖相关功能：出价、保证金、自动延长时间、成交确认

## 3. 非功能需求

### 3.1 安全要求（重点）

| 安全维度 | 要求 |
|---------|------|
| 数据传输 | 全站 HTTPS，API 接口 TLS 1.3 |
| 认证鉴权 | JWT Token + Refresh Token，敏感操作二次验证 |
| 权限控制 | RBAC 基于角色的权限管理，卖家/买家/管理员三端隔离 |
| 接口安全 | API 签名校验、防重放攻击、频率限制 |
| 数据安全 | 用户敏感信息（身份证、手机号）加密存储 |
| 支付安全 | PCI-DSS 合规要求，支付信息不落盘 |
| 防攻击 | SQL 注入防护、XSS 过滤、CSRF Token |
| 日志审计 | 所有敏感操作记录操作日志，可追溯 |
| 卖家资料保护 | 认证后卖家资料仅管理员可修改，防止信息篡改 |

### 3.2 性能要求

- 页面加载 ≤ 2秒（首屏）
- API 响应 ≤ 500ms（95%）
- 支持 1000+ 并发用户
- 图片加载使用 CDN + 懒加载

### 3.3 可扩展性要求

- 模块化架构，各业务域解耦
- 事件驱动机制，新业务模块（如拍卖）通过事件集成
- 数据库按 Schema 分离，支持未来分拆独立服务
- 前端按微前端架构预留，支持独立模块开发部署（可选）

### 3.4 可用性要求

- 系统可用性 ≥ 99.9%
- 定时备份数据库
- 核心业务（下单、支付）支持降级/熔断

## 4. 技术方案概要

### 4.1 整体架构

采用**模块化单体 + 事件驱动**架构：

```
前端 (Vue 3) → 统一 API 网关 → 模块化后端 (Spring Boot)
                                      ↓
                              消息队列 (RabbitMQ) 解耦模块
                                      ↓
                              PostgreSQL (模块化 Schema)
```

### 4.2 前后端技术栈

| 层次 | 技术 | 用途 |
|------|------|------|
| 前端框架 | Vue 3 + Composition API | 商城前台、卖家中心、管理后台 |
| 前端UI | Element Plus | 统一 UI 组件库 |
| 国际化 | Vue I18n | 四国语言切换 |
| 后端框架 | Spring Boot 3 + JDK 21 | 业务服务 |
| 安全框架 | Spring Security + JWT | 认证授权 |
| 数据库 | PostgreSQL | 主数据库 |
| 缓存 | Redis | 高性能缓存、分布式锁 |
| 消息队列 | RabbitMQ | 模块间事件通信 |
| 搜索引擎 | Elasticsearch | 商品全文搜索 |
| 文件存储 | MinIO / AWS S3 | 图片、证件文件存储 |

### 4.3 多域名部署

| 域名 | 用途 |
|------|------|
| `store.xxx.com` | 商城前台（买家端） |
| `admin.xxx.com` | 管理后台 |
| `seller.xxx.com` | 卖家中心 |
| `api.xxx.com` | API 统一入口 |
